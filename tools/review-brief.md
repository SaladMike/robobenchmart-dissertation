## 2. 论文的核心主张结构

这是判断"前后是否一致"的基准。请拿它去衡量每一章。

**论文声称的：**

- 基准仪器可用。店面能生成、保持通道、可复现；网格简化把可仿真规模从 4 个
  货架单元推到 118 个；一套观测—动作接口喂了四个内部结构迥异的模型。
- 演示管线可用。2,976 条成功轨迹、1,401,169 个 transition，无人工遥操作。
- 失败发生在哪个阶段是可测的，即使成功率很低。

**论文明确不声称的（这部分最容易被写漏）：**

- 不声称哪个模型更强。主结果表内任意两格的 Wilson 置信区间都重叠。
- 不声称哪个任务更难。
- 不声称测到了分布偏移下的性能退化。二十个模型—任务对里，
  从 Pose 到 Layout 的变化有十五个是 0 个百分点。
- 不声称知道近零成功率的原因。训练在预设步数到点时停止，未做验证集收敛判断，
  因此算力、语料、优化配置与任务难度四者互相混淆，本研究不能分离。

**三个研究问题的当前答案：**

| | 答案 |
|---|---|
| RQ1（场景生成） | 是 |
| RQ2（演示采集是否足以适配策略） | 前半是；后半只在最弱意义上成立 |
| RQ3（策略在偏移下的行为） | **无法回答**——注意不是"答否" |

RQ3 从"无法回答"滑向"答否"是最需要警惕的一类错误。二者的区别是：
前者说实验没测出来，后者说策略不行。

## 3. 请检查的事项

按重要性排序。

**3.1 摘要与结论是否说同一件事**

摘要（`abstract.tex`）和第 6 章结论是读者唯一保证会读的两处。
请逐句比对：摘要承诺的每一项，结论是否兑现；结论给出的每一项，
摘要是否预告过或至少不矛盾。

特别注意归因的强度是否一致——有没有一处说"因为算力不足"，
另一处说"无法确定原因"。

**3.2 超出证据的表述**

搜索仍在做比较或排序的句子。判据见第 2 节：置信区间重叠 →
模型间、任务间、条件间的比较都不成立。

形如"X 比 Y 强"、"某任务更难"、"随偏移退化"、"表现最好的是"
这类措辞，无论出现在哪一章，都需要核对表格是否支持。

**3.3 章节之间的承诺与兑现**

第 1 章的引言段和"论文结构"段对后续各章做了预告；
第 3、4 章多处说"结果章会处理 X"；第 5 章多处回指第 3、4 章。
请检查这些指涉是否都还成立——某章承诺讨论 X，而 X 已经不再被讨论，
是这次大幅修订后最可能残留的问题。

**3.4 数字一致性**

正文散文中的每个数值都应与表格对得上。已知关系：

- 主表 `tab:main-results` 每格 = 逐商品表 `tab:per-item` 对应几列的均值

- 失败 episode 总数 = 2,906（出现在摘要、ch1、ch4、ch5、著作声明五处）
- 演示语料 2,976 episodes / 1,401,169 transitions

**3.5 未经核实的外部断言**

论文有一条贯穿全文的写作原则：**凡是本研究自己无法证实的外部事实，
都应替换为本研究自身的可证陈述**。修订过程中已按此清理过多轮，但可能有遗漏。

请核查任何关于 Octo / SmolVLA / π₀ / π₀.₅ **原论文**做了什么的陈述、
关于 ManiSkill3 等外部系统能力的陈述、以及"标准做法是……"这类惯例断言。
另请抽查 `\cite` 与被引内容是否真的支持该处论点。

无法判定真伪的，标为"存疑"并说明需要什么证据，不要猜测。

**3.6 段落内部的逻辑**

前五项是跨章的。这一项是局部的：段落里有没有前提推不出结论、
转折词与实际语义相反、或者一句话自我抵消的情况。
