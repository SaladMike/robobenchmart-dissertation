\section{The 42 atomic evaluation configurations}

This appendix provides the complete, unaggregated evaluation results across all 42 atomic task configurations evaluated in this study. Both Octo and $\pi_{0.5}$ were evaluated for exactly 30 episodes per configuration, yielding 1,260 rollouts per model (2,520 rollouts total). 

The 42 configurations span four progressive distribution tiers:
\begin{itemize}[leftmargin=2.5em,itemsep=0.2em]
  \item \textbf{Seeds (Configs 1--12)}: Re-executes the nominal training configurations (\texttt{\_train} suffix) with base offset zero.
  \item \textbf{Pose (Configs 13--24)}: Re-evaluates identical task--item triplets under localized base pose perturbations ($\pm 25$~cm translation, $\pm 22.5^{\circ}$ yaw; seed 10000; \texttt{\_robo} suffix).
  \item \textbf{Layout (Configs 25--36)}: Introduces novel store floor plans and textures (evaluation seed 42000; \texttt{\_uns} suffix). Note that door tasks reuse training store plans, varying only textures and starting poses.
  \item \textbf{Pairing (Configs 37--42)}: Evaluates zero-shot task--item composition by commanding pick-and-place tasks with products withheld during training demonstrations for that specific task (\texttt{\_ood} suffix). Door tasks have no product targets and are structurally omitted.
\end{itemize}

\section{Artifact provenance and verification manifests}

All 2,520 evaluation episodes and their associated outputs are recorded in the project repository. Each configuration directory preserves 30 MP4 video recordings (stored via Git LFS), execution logs, and output metadata.

\begin{itemize}[leftmargin=2.5em,itemsep=0.2em]
  \item \textbf{Octo Release}: Checkpoint \texttt{1000000} from \texttt{emb-ai/RoboBenchMart\_octo} (revision \texttt{f3c8de450fc08fb5737d32442a2b1e6ab2993244}), evaluated under batch \texttt{octo\_parallel\_20260928\_021558}.
  \item \textbf{$\boldsymbol{\pi_{0.5}}$ Release}: OpenPI configuration \texttt{pi05\_eval\_rbm} from \texttt{emb-ai/RoboBenchMart\_pi05} (revision \texttt{533ad107347c3568dc2456d1586b665889f0ed18}), evaluated under batch \texttt{pi05\_parallel\_20261002\_105333}.
  \item \textbf{Scene Packages}: \texttt{emb-ai/RoboBenchMart\_demo\_envs} (revision \texttt{3dabfaaf9bdf2ba886264a1160dab68ac7043d00}), comprising 466 scene files (87,643,138 bytes).
  \item \textbf{Integrity Manifests}: All 2,688 generated output files are documented in \texttt{artifact\_manifest.csv} and \texttt{log\_manifest.csv}, accompanied by cryptographic SHA-256 checksums in \texttt{SHA256SUMS.txt}.
\end{itemize}

Cryptographic integrity can be audited across all artifacts using the provided Python verification routines:
\begin{verbatim}
import csv, hashlib
from pathlib import Path
for manifest in ('artifact_manifest.csv', 'log_manifest.csv'):
    with open(manifest, newline='') as f:
        for row in csv.DictReader(f):
            p = Path(row['relative_path'])
            assert p.stat().st_size == int(row['size_bytes']), p
            h = hashlib.sha256(p.read_bytes()).hexdigest()
            assert h == row['sha256'], p
\end{verbatim}
